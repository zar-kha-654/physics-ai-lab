# ⚛️ Physics AI Lab

Physics AI Lab is an interactive educational platform for learning physics through experimentation and AI-powered explanations.

## Features

- Interactive physics simulations
- Newton's Second Law
- Projectile Motion
- Adjustable physical parameters
- Visual experimentation
- AI Physics Tutor powered by Groq

## Technology

- Python
- Streamlit
- Matplotlib
- NumPy
- Groq API

## Educational Goal

Instead of only reading formulas, students can change variables, observe physical behavior, and ask an AI tutor why the results occur.
